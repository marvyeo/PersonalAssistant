# Read first
**FIRST, before anything else:** start your first reply with "Rename this chat to: **Personal Assistant ver N**", taking N from the **Next chat name** line at the top of `Personal Assistant-Project State.md`. Then bump that number by 1 in your first commit.

1. `git pull`, then read `Personal Assistant-Project State.md` before doing anything. It is this project's memory.
2. Be frugal: recommend the cheapest capable model, keep chats compact, and ask the user to move to a new chat when context grows.
3. **Every commit that changes the project also updates `Personal Assistant-Project State.md`** (change log line + any section it made wrong). Never push without it.
